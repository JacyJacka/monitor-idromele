# Monitor idromele

Monitoraggio automatico della fermentazione dell'idromele con un densimetro digitale iSpindel: misura della gravità specifica, rilevamento della fine fermentazione e notifiche su Telegram. Pensato per girare su Raspberry Pi.

Il progetto è in fase di pianificazione. Il software verrà sviluppato prima con un simulatore, in attesa dell'hardware.

## Struttura

- `docs/00-pianificazione.md` — piano generale, metodo di lavoro e stato delle fasi
- `docs/01-fase0-regole.md` — regole di fermentazione e avvisi
- `ricette/` — ricette di riferimento
